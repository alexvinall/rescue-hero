# Rescue Hero

Rescue Hero is a lightweight static website project with a hero-style landing page focused on emergency and rescue themed branding.

## Project structure

- `index.html` — Main webpage markup.
- `styles.css` — Styling for layout, colors, and responsive presentation.
- `script.js` — Front-end JavaScript behavior.
- `images/` — Image assets used by the page.

## Getting started

Because this is a static site, you can open `index.html` directly in your browser.

For a better local development experience, run a simple local server from the project root, for example:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
